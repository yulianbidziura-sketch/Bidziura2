## Як відкрити проєкт

Кожна робота — самодостатня папка. Для `bikeshop`:

```bash
cd bikeshop
./mvnw spring-boot:run      # http://localhost:8080/api/bikes
./mvnw test                 # 24 тести
```

У IntelliJ IDEA відкривати саме папку роботи (`bikeshop`), а не корінь
репозиторію — тоді IDEA побачить `pom.xml` і підтягне залежності.
Покрокова інструкція — `bikeshop/ЗАПУСК-В-IDEA.md`.
